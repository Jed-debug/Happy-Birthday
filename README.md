How to use
1. Put your parachuting cat image in the `images/` folder and name it `cat-parachute.png` (or update the `src` in `index.html`).
2. Edit the message paragraphs in `index.html` to add your text.
3. Open `index.html` in a browser or serve the folder with a simple server:

```bash
python -m http.server 8000
# then open http://localhost:8000 in your browser
```

Controls
- Use the `Drop speed` slider to adjust how quickly the cat descends relative to scroll.
- Click `Start Auto Drop` to let the cat descend slowly on its own.
